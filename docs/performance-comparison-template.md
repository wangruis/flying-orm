## 结论规则

- 保留两边完整 JSON 原始结果、运行命令和数据库配置，不能只留汇总数字。
- 吞吐、平均延迟和 P95/P99 分开比较，不用单一最好值代表整体性能。
- 发生超时、连接失败、死锁或取消时，单独记录错误分类和比例。
- JVM 预热不足、环境被其他任务干扰或两边场景不等价时，本轮结果作废并重跑。
