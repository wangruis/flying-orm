# 实体注解语义与生命周期实施计划

1. 用少量契约测试固定 `@MappedSuperclass` 和 `@Column` 的写入规则。
2. 扩展只读实体元数据，并让实体取值计划按 insert、update、upsert 过滤字段。
3. 让 ReactiveFormRepository 的单行和批量写入统一使用上述计划，补齐继承字段读写。
4. 增加标准生命周期回调解析器和原生响应式监听器，回调在订阅阶段执行。
5. 对齐查询回调、删除回调、批量部分成功与 UNKNOWN 的边界，再桥接同步门面。
6. 只跑定向测试、模块编译和无用 import 检查；真实数据库认证沿用最终认证阶段统一执行。
