# flying-orm 企业版 V1 冻结路线

这份文件是后续开发和进度汇报的唯一任务口径。新增工作只能归入已有编号，不能临时增加 V1 主线。

## V1 主线

1. PostgreSQL Array 基础层：首版完成，真实库验证归第 8 项。
2. 数组条件 AST：首版完成。
3. JSON 查询能力深化：首版完成，已覆盖 path、包含、存在和数组元素条件。
4. 类型系统补齐：首版完成。枚举、Boolean、数值、UUID、Java Time、数组、JSON 和 LOB 已有统一转换边界；应用可在 `FlyingOrmClients.Builder` 配置只读 `ValueCodecRegistry`，条件、单条写入、批量和实体回读会复用同一个实例。驱动特殊返回值和数据库特有类型的真实环境认证归第 8、9 项。
5. Scope 安全收口：首版完成，后续发现问题仍归本项修复。
6. 动态表单 DDL 企业增强：V1 已完成。字段重命名必须显式声明，类型变更、删列、索引删除/重建必须显式放开；默认安全模式只生成可安全执行的 SQL，并把主键、外键等高风险变化留给上层审核。审核结果、反向结构 SQL、回滚缺口和在线 DDL 强制模式已经落地，目标数据库 DDL 已纳入最终真实库认证。
7. 元数据与缓存深化：V1 已完成。Caffeine 容量/TTL、并发同 key 合并加载、失败后重试、DDL 成功后的精确表失效、失效竞态保护和框架无关统计快照已完成；JMH 与真实数据库长跑已经覆盖缓存和元数据主链路。
8. 真实数据库兼容闭环：MySQL 8.4.10 和 PostgreSQL 17.10 的第一轮真实驱动功能、两批事务故障、连接池并发稳定性及首轮固定资源性能长跑已完成。CRUD、JSON、Array（PostgreSQL）、LOB、元数据、乐观锁、有界并发、ATOMIC/INDEPENDENT、重复键、超时取消、NOWAIT、死锁、会话终止、UNKNOWN 回执恢复、小池耗尽恢复、慢消费者取消和持续有界并发共 31 个目标场景通过；另有查询、更新和两类批量写入共 8 个性能场景零错误、最终零借出和零等待。固定版本 Docker Compose、健康检查、独立驱动 JVM、统一入口和脱敏证据目录已经就绪。
9. Oracle、SQL Server 深度兼容：代码层和三轮真实库认证已完成，两库提升为正式支持。两库分别通过动态表单 DDL/CRUD/MERGE、JSON、LOB、乐观锁、主外键元数据、有界并发、ATOMIC/INDEPENDENT、重复键分类、连接池耗尽恢复、慢消费者取消、持续并发、死锁、显式锁超时、会话终止和 UNKNOWN 恢复，各 14 个目标场景。真实 Oracle MERGE 的 BLOB/CLOB 绑定、回执空字符串和 ORA-30006 分类已经闭环；SQL Server 的 1222 分类也已实库确认。SQL Server 主动关闭连接时的 dropped 日志保留为驱动已知限制，但业务结果、连接恢复和资源回收均已通过；不支持 OpenGauss。
10. 异常与故障恢复统一：主链路已覆盖四库稳定错误分类、包装异常、批量失败类型和 UNKNOWN 回执；testkit 已支持按操作和调用序号注入连接中断、死锁、锁超时、取消、延迟和 UNKNOWN 结果。MySQL/PostgreSQL 的真实重复键、查询超时、NOWAIT、死锁、会话终止和 UNKNOWN 回执确认/重放已经通过；Oracle/SQL Server 的真实死锁、显式锁超时、会话终止和 UNKNOWN 确认/重放也已通过。
11. 并发与事务稳定性：ATOMIC/INDEPENDENT、乐观锁、取消状态、UNKNOWN、连接获取超时、通用有界并发探针和确定性故障脚本已完成；四库的真实 ATOMIC 回滚、INDEPENDENT 分片隔离、死锁释放、提交确认恢复、连接池耗尽与恢复、下游需求和中途取消、持续有界并发后的资源归还已经通过。MySQL/PostgreSQL 另已通过完整超时取消批次，首轮固定资源性能长跑也验证 8 个场景零错误且最终连接全部归还。
12. 性能优化与基线：V1 基线、真实库长跑和发布后专项定位已经完成。JMH 覆盖条件、渲染、批量计划、实体映射、元数据缓存及执行保护/观测包装；真实库 Runner 覆盖查询、更新、ATOMIC 和 INDEPENDENT，并输出吞吐、延迟分位、错误、CPU、堆和连接指标。MySQL 单行自动提交更新的专项观测表明，P99 主要落在 SQL 执行及持久化提交阶段，而不是连接获取；固定 8 行显式事务对照把业务行吞吐提高约 3.60 倍，但它只适用于上层明确允许共同提交的业务，ORM 不会自动合并事务。所有专项运行均为零业务错误且连接全部归还。原生 Linux 或独立磁盘交叉验证已按决定跳过，因此历史 RC 的 MySQL 单行更新硬门禁仍记录为未通过，不能改写成性能已过线；专项定位本身已经结束，不再作为当前开发任务。
13. 公共 API 收口：V1 代码层最终复核完成。`FlyingOrmClients.Builder` 统一承接方言识别、业务条件解析器、普通 SQL 执行保护、默认批量策略、同步等待和 Caffeine 元数据缓存，早期创建方法重载矩阵已经移除；批量请求统一为 `BatchWriteRequest`，List 与 Publisher 输入共享 `writeBatch(...)` 的事务、分片、结果、恢复和观测语义。默认批量仍为 ATOMIC，执行包装器、数据库专用元数据 reader 和内部反射 `MappingPlan` 已收回包内。同步 API 明确为 R2DBC 桥接，只保留 `Sync*` 正式入口并完整转发显式执行保护。稳定公共包已经讲清职责、线程安全、安全和订阅边界；批量参数数组所有权与重复订阅语义已经明确，分页极值不再溢出，SQL/批量观测和分片结果会拒绝互相矛盾的状态。
14. 发版文档与交付：`1.0.0` 版本、`v1.0.0` Git 标签和 GitHub 源码发布已经完成。数据库支持矩阵、稳定错误码手册、使用与升级边界、候选版说明、已知限制、依赖审计入口和发布检查清单已经建立；Java/Maven/依赖收敛门禁、项目基础元数据与源码/Javadoc 构建也已落地。按当前决定，不添加项目许可证，不发布 Maven 仓库制品，不配置产物签名，并明确跳过需要 `NVD_API_KEY` 的正式漏洞审计；不能据此声称已经通过正式漏洞扫描。

## 并行任务

15. 平级 Spring Boot 示例和上层适配，不进入主项目。
16. 上层业务继承式 API 与动态表单示例。
17. 设备归属、组织树、用户分享、告警时间范围等通用 Scope 协作示例：文档首版完成。

## V1 后置增强

19. PostgreSQL Vector：已完成，pgvector 写入、读取和距离排序已通过真实 PostgreSQL 认证。
20. SQL 模板逃生口：已完成，模板由服务端注册，值参数绑定，标识符插槽受控，前端不能透传 SQL。
21. 更完整的 flying-orm 自有实体注解语义和映射事件：已完成，V2 不读取 Jakarta Persistence 实体注解。
22. Schema 隔离、独立数据库隔离、数据库原生 RLS：已完成代码能力；PostgreSQL Schema/RLS 在单连接池复用下的设置、清理和串租户隔离已经通过真实库认证。
23. 更高级的迁移回滚和在线 DDL 策略：已完成首版，包含审核结果、反向结构 SQL、明确回滚缺口和在线 DDL 强制模式。

## V1 发布后增强

24. 游标分页和深分页优化：已完成。支持复合升降序 keyset 条件、无 count 单 SQL 查询、下一页游标和同步桥接；调用方应把唯一键放在排序末尾。
25. 在线 DDL、数据迁移与数据级回滚：已完成。在线 DDL 继续复用审核、计划指纹、锁超时和外部工具边界；新增参数化数据迁移计划，失败后只逆序补偿已经成功的步骤，并明确区分完整回滚与回滚失败。
26. Oracle、SQL Server 正式支持：已完成。基于已经归档的三轮目标版本真实库认证提升支持等级，驱动日志限制继续公开记录。
27. 元数据缓存指标接入上层监控：已完成。`MetadataCacheMetricsBridge` 输出稳定指标名，不让主项目依赖 Micrometer、OpenTelemetry 或其他监控框架。
28. 数据库特殊类型和列别名适配：已完成首版。`DriverValueAdapter` 允许按驱动解包特殊返回值，`RowMapper.withAliases(...)` 支持显式列标签映射，并兼容带表限定符及常见引用符的列标签。
