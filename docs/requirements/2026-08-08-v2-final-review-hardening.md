# V2.0.0 最终审查加固

## 状态

已完成。该批只收紧数据所有权、事务失败收尾和公开错误脱敏，不新增功能，不改变公共 API、SQL、方言或正常事务语义。

## 已确认契约

- 批量 `Publisher<Object[]>` 允许上游复用同一个参数数组。JDBC 与 R2DBC 必须在接收每一行时立即保存独立快照，不能等分片形成后再复制。
- 参数数组只复制一次；分片随后冻结列表结构，避免为了修复正确性引入重复热路径分配。
- 生成键等事务内回调或驱动抛出 `RuntimeException`/`Error` 时，自有 JDBC 事务仍必须回滚。回滚无法确认时结果为 `UNKNOWN`，连接进入隔离/失效流程。
- 数据迁移补偿失败的公开结果只保留稳定说明，不携带驱动异常原文、SQL、连接信息或业务值。
- 动态表单构建校验和实体枚举结果映射只报告稳定错误类别，不回显表单名称、字段名称或数据库业务值。
